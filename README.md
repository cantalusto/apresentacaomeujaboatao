# Meu Jaboatão - Apresentação

Apresentação oficial do aplicativo Meu Jaboatão, desenvolvido pela **DigitalNest**.

## 🚀 Sobre o Projeto

O Meu Jaboatão é um aplicativo inovador que conecta a Prefeitura de Jaboatão dos Guararapes aos cidadãos, facilitando o acesso a serviços públicos essenciais.

### ✨ Funcionalidades Principais

- 💳 Pagamento de IPTU via Pix
- 🏥 Localização de postos de saúde e farmácias populares
- 💼 Vagas de emprego
- 💉 Calendário de vacinação
- ♻️ Coleta seletiva
- 🚨 Sistema de solicitações (buracos, postes quebrados, etc.)
- ❤️ Doações

## 🛠️ Tecnologias

- React Native (Mobile)
- React.js (Web)
- Supabase (Backend)
- Firebase (Notificações)
- Google Maps API / OpenStreetMap
- Ant Design (UI)
