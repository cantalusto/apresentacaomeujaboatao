O que é o Meu Jaboatão?

Inspirado no conceito do Conecta Recife, o Meu Jaboatão é uma plataforma completa que conecta você aos serviços da prefeitura, facilitando o acesso a informações e serviços essenciais para melhorar a qualidade de vida na cidade.

📱 Disponível para Android e iOS

🔧 Stack Tecnológica

Frontend & Mobile

  • React / React Native
  • TypeScript
  • Ant Design (UI)
  • Leaflet (Mapas)
  • PWA Support

Backend & Infraestrutura

  • Supabase (Database + Auth)
  • Node.js + Express
  • PostgreSQL
  • Firebase Cloud Messaging
  • Cloudinary (Storage)

🔌 Integrações e APIs

  • 🔐
    Autenticação: Supabase Auth / Firebase Auth (CPF, E-mail, Google)
  • 💰
    Pagamentos: Pix via Gerencianet / Pagar.me / Mercado Pago
  • 🗺️
    Mapas: Google Maps API / OpenStreetMap + Leaflet
  • 🔔
    Notificações: Firebase Cloud Messaging (Push Notifications)
  • ☁️
    Upload de Imagens: Supabase Storage / Cloudinary
